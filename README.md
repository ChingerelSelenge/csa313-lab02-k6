## Хэмжсэн үзүүлэлтүүд

Тестийн үед дараах performance үзүүлэлтүүдийг хэмжсэн.
- p90: request-үүдийн 90% нь энэ хугацаанаас бага хугацаанд хариу өгсөн response time
- p95: request-үүдийн 95% нь энэ хугацаанаас бага хугацаанд хариу өгсөн response time
- Throughput: нэг секундэд боловсруулсан HTTP request-ийн тоо
- Error rate: амжилтгүй болсон HTTP request-ийн хувь

## SLO (threshold) сонголтын тайлбар
 
Миний 5 VU дээрх baseline p95 нь 286.35ms байсан. Үүнээс SLO-гоо дараах байдлаар тооцож гаргасан:
 
```
SLO (p95) = baseline p95 × 1.5
          = 286.35 × 1.5
          = 429.525ms
          = 430ms
```
Иймээс response time-ийн SLO threshold-ийг p(95) < 430ms гэж тохируулсан. Бодит систем дээр ачаалал нэмэгдэхэд хариу хугацаа хэвийн хэмжээгээр удааширдаг тул baseline-аасаа 1.5 (50%) дахин хүртэл зөвшөөрөх боломжтой гэж үзсэн. 
 
Error rate-ийн SLO-г http_req_failed < 1% гэж тохируулсан. Алдаатай request-ийн хувь бага байх нь системийн тогтвортой ажиллагааг илэрхийлэх тул 1%-иас бага байхаар шаардлага тавьсан.

## Дүгнэлт 
 
Энэхүү лабораторийн ажлаар Grafana k6 ашиглан веб системийн performance болон load testing хийж, latency, throughput болон error rate гэсэн үндсэн үзүүлэлтүүдийг хэмжсэн. Эхний 5 VU baseline тестийн үед p95 response time 286.35 ms, error rate 0.00% байсан. Мөн HTTP request-ийн throughput 7.215437 request/sec байсан. Baseline-ийн p95 утгыг үндэслэн SLO threshold-ийг 430 ms гэж тогтоосон. Энэ нь baseline p95-ийн ойролцоогоор 1.5 дахин их утга бөгөөд performance-ийн боломжит хэлбэлзлийг зөвшөөрөх зорилготой. Дараагийн 5, 30, 100 VU тестээр ачаалал нэмэгдэх үед response time болон throughput хэрхэн өөрчлөгдөж байгааг харьцуулсан. 5 VU-ийн тестийн үед p95 response time 294.90 ms, throughput 7.392032 req/s, error rate 0.00% байсан. 30 VU дээр p95 307.45 ms болж бага зэрэг өссөн боловч error rate 0.00% хэвээр байсан. 100 VU дээр p95 250.52 ms болж өмнөх хоёр түвшнээс бага гарсан. Харин throughput нь 5 VU-ийн 7.392032 req/s-ээс 30 VU дээр 43.943211 req/s, 100 VU дээр 149.962039 req/s болж тасралтгүй өссөн. Иймээс энэхүү тестийн үр дүнгээр ачаалал нэмэгдэхэд throughput мэдэгдэхүйц өссөн гэж ажиглагдсан. Гурван түвшний аль алинд нь error rate 0.00% байсан тул тестийн хугацаанд request боловсруулах тогтвортой байдал сайн байсан. 5 VU baseline p95-ийг үндэслэн SLO threshold-ийг 430ms гэж сонгосон бөгөөд энэ босго нь baseline-ийн 1.5 дахин утгад ойролцоо байна. Харин threshold тест дээр 286.44ms байна. Энэ нь тест тус бүрийн үед response time бага зэрэг өөрчлөгдсөнөөс болсон гэж бодож байна. Энэхүү дадлагаар өөр өөр VU-ийн үед performance metric-үүдийг харьцуулж, threshold ашиглан системийн гүйцэтгэлийг тодорхой шаардлагын дагуу үнэлэх боломжтойг ойлгосон.
